A free, self-hosted remote cache for Nx.
Small, fast, yours.

One 4 MB static binary. Azure Blob, S3, GCS or local disk behind it. A live dashboard in front of it. No subscription, no vendor, nothing to operate.

Quick start ghcr.io image
⚡

Built for the hot path

Streaming in both directions, create-only writes, an in-memory tier for hot artifacts, sub-millisecond misses.

☁️

Any object store

Azure Blob first, with Workload Identity. S3, GCS, local disk and memory behind the same URL switch.

📊

Built-in dashboard

Hit rate, throughput, p50/p90/p99, retention, and a live feed that links every artifact to the CI run that produced it.

🔒

Kubernetes-native

Scratch image, non-root, probes, Prometheus metrics, graceful drain, retention sweeper, manifests included.

Two environment variables

That is the whole client setup, on every developer machine and in CI.

# run it
docker run -p 3000:3000 -e NX_CACHE_STORE_URL=az://nx-cache/ -e AZURE_STORAGE_ACCOUNT_NAME=… -e NX_CACHE_TOKEN=… ghcr.io/misterpandapooh/nx-remote-cache

# point Nx at it
export NX_SELF_HOSTED_REMOTE_CACHE_SERVER=https://nx-cache.example.com
export NX_SELF_HOSTED_REMOTE_CACHE_ACCESS_TOKEN=…;run=$GITHUB_RUN_ID;repo=$GITHUB_REPOSITORY   # context after the secret, optional
